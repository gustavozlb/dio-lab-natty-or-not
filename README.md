# 🎥 Vídeo Gerado por IA – Apresentação Pessoal

## 📒 Descrição

Este projeto foi desenvolvido como parte de um desafio da DIO, cujo objetivo era criar um vídeo utilizando inteligência artificial sobre um tema de livre escolha. Optei por produzir um vídeo de apresentação pessoal, destacando quem sou, minhas principais habilidades e meus interesses na área de tecnologia.

## 🤖 Tecnologias Utilizadas

Para a criação do projeto, utilizei as seguintes ferramentas:

* **D-ID:** utilizada para gerar a narração por meio de inteligência artificial.
* **DeeVid AI:** utilizada para sincronizar o áudio com uma imagem, criando uma apresentação em vídeo com movimentos faciais naturais.

## 🧐 Processo de Criação

O desenvolvimento começou com uma pesquisa por ferramentas gratuitas que oferecessem boa qualidade na geração de vídeos com IA. Após comparar diferentes opções, escolhi o **D-ID** para criar a narração e o **DeeVid AI** para animar a imagem utilizada no vídeo. A combinação dessas ferramentas proporcionou um resultado de boa qualidade, tanto no áudio quanto na animação.
